QUICK GUIDE

Using Shiftly

View the calendar: Shiftly signs you in anonymously so you can see shared updates. Google sign-in is required to save changes.

Edit a day: Select a date, choose a shift state, or add a note. Hospital appointments can be exported as an .ics file.

Move between months: Use the arrows or swipe left and right on the calendar.

Sync: Synced means the latest calendar data is connected to Firebase. Changes from the other device appear automatically.
